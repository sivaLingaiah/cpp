C++ Concept Practice & Learning

Welcome to my C++ repository! This space contains code examples, practice exercises, and fundamental concepts I'm exploring as I learn modern C++.

🚀 Topics Covered

Fundamentals: Variables, data types, control flow, loops, functions, and standard I/O

Pointers & Memory: References, raw pointers, dynamic memory allocation (new/delete), dynamic arrays

Object-Oriented Programming (OOP): Classes, objects, encapsulation, inheritance, polymorphism, constructors, and destructors

Standard Template Library (STL): std::vector, std::string, std::map, iterators, and utility functions

File I/O: Reading from and writing to files using fstream

💻 How to Run

To compile and run any .cpp file locally using g++:

# Compile the source file
g++ -std=c++17 -Wall main.cpp -o main

# Execute the binary
./main


📌 Requirements

C++17 compatible compiler (g++, clang++, or MSVC)

Make or CMake (optional, for multi-file builds)
